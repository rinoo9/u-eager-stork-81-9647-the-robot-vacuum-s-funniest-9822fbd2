The Robot Vacuum's Funniest Excuse — a single line (at most 120 characters) in which a robot vacuum explains why it missed a spot. The vacuum skipped the spot because the dust bunny there unionised, and it refuses to cross a picket line made of pet hair.

## Run it

```sh
python3 main.py
```

This writes the one-line excuse to `/output/entry.txt` (or `$OUTPUT_PATH`).
